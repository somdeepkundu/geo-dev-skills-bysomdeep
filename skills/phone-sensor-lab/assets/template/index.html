    Temperature, humidity and pressure from a sensor that speaks the standard Environmental Sensing service. Pressure gives height differences: about 8 m per hPa.

    NFC point tags

    checking

    Stick a cheap NFC tag on a plot post. Write the point once; on every revisit, a tap logs it with today's GPS and how far that is from the original.
